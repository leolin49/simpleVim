#### Usage:
<leader> = ''
```Plain Text
----------------------------------- Basic ----------------------------------------------
<F1>            Show the help doc.
<F2>            Create a new shell window in the current terminal.
<F3>            Clear the file content and Paste.
<F4>            Copy the entire file contents to system clipboard.
<F5>            Run cmd 'pypy3 file.py < input'.
<F9>            Open/Close the tagbar on the right. 
,,              Clean the search highlight.
;               Open/Close the nerdtree list.
<Ctrl>h         Switch to the left buffer file. 
<Ctrl>l         Switch to the right buffer file. 
<leader>py      Open the python shell(pypy3).
------------------------------- Code Navigation ----------------------------------------
gd              Go to the Defination.
gr              Go to the Reference.
Ctrl-i          Go to the next posistion in the jump list.
Ctrl-o          Go to the previous posistion in the jump list.
------------------------------------ Search --------------------------------------------
f               Open/Close the CtrlSF window.
F               Search the word where the cursor is located.
:CtrlSF xxx     Search the word 'xxx' in current directory.
----------------------------------------------------------------------------------------
```
